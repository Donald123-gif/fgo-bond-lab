# 牵绊编队使用指南

[打开编队页面](https://donald123-gif.github.io/fgo-bond-lab/#workspace) · [返回项目说明](../README.md)

在网页的「队伍编成」标题旁点「使用指南」，可以随时查看四步简版。

## 第一次算一队

1. 在页首选「国服 · CN」或「日服 · JP」。到「设定出发条件」填写**御主等级**和**关卡基础牵绊**，确认编队 COST 上限和自有从者人数。基础牵绊填一场关卡还没加上礼装、前排和茶壶奖励时的数值。
2. 在「优化候选配置」打开「从者候选池」，选中自己可用的从者，按实际情况设置卡片下方的「牵绊状态」，点**确认候选配置**。再打开「牵绊礼装候选」，选中持有的礼装，核对「满破」，确实要求装备的才勾「必带」。同样点确认。初始候选是演示配置。
3. 回到「队伍编成」。一定要带的自有从者，点「选择从者」放入队伍；其余自有槽可以留空。在「＋助战」位下方选择实际借用的礼装，并核对满破状态。助战礼装有独立的设置。
4. 保持「优化目标」为「全队总牵绊最大」，点「寻找最优队伍」。手机也可点底栏「计算最优」。结果直接填回编队。
5. 看卡片下方每人的收益和灵基，再看汇总栏「全队牵绊 / 次」与队伍 COST。想保留这套配置，点「保存 / 载入编队」，填写名称并点「保存当前编队」。

## 选人、选礼装与换位

| 想做什么 | 页面上怎么做 |
| --- | --- |
| 搜索一张卡 | 在选择弹窗输入名称、图鉴编号或已收录的别名。例：「C呆」「术呆」可找阿尔托莉雅·卡斯特；在普通礼装槽搜索「宝石翁」「黑杯」可找到相应礼装。 |
| 缩小范围 | 点「筛选」。从者可组合职阶、稀有度、宝具卡色与特性；礼装可组合稀有度与效果类型。同组多选满足任一项即可，跨组须同时满足。点「确认」生效；要清除条件，点「重置筛选」再「确认」。 |
| 改变列表顺序 | 从者默认「稀有度 高→低」，也可按图鉴或从者等级排序。礼装默认「礼装等级 高→低」，还支持等级升序、Cost 升降序、稀有度和图鉴排序。等级取自手动登记，未设置时按 Lv.1。 |
| 装备或移除 | 在槽位弹窗点卡面立即返回。礼装可先改卡片下方的等级与满破，再点卡面装备。要移除，重新打开该槽并点「清除此槽位」。候选池是多选，点「确认候选配置」才提交持有与满破等修改。 |
| 保住具体槽号 | 手动选入的自有从者须入队，但计算时可以换位。点该槽上方的锁可同时固定人和位置；点「概念礼装」旁的锁可单独固定礼装位置。只想固定礼装时，可让从者保持自动。 |
| 交换站位 | 拖动从者卡或编号手柄，整槽从者和装备一起换位。拖动卡下的普通礼装，只交换普通礼装。主动换位后，锁定约束跟随对应的人或装备。也可依次点击两个编号手柄，或用 Tab 聚焦手柄后按 Enter 选择，Esc 取消。 |
| 在手机上换位 | 平时左右滑动看六个槽，也可点「首发 1–3」「替补 4–6」跳转。点「调整站位」后拖动卡面或普通礼装，结束时点「完成换位」。底栏「编队」「条件」「候选池」可跳到相应区域。 |

首发为屏幕上的 1–3 位，替补为 4–6 位。「＋助战」可以换到后排；自有前排人数由当前站位决定。减少自有从者人数前，请先清掉即将停用槽中的固定从者或礼装。

## 哪些设置会改变答案

| 设置 | 填法与影响 |
| --- | --- |
| 御主等级 / 编队 COST 上限 | 当前快照中国服等级 1–190，日服 1–200。改御主等级会重算 Cost 上限；如需手动覆盖，在改等级后再填上限（0–300）。从者卡上的 Lv.（1–120）只用于显示与等级排序。 |
| 关卡基础牵绊 / 自有从者 | 基础牵绊可填 0–100000 的整数；自有从者 1–5 人。助战从者和助战礼装不占 Cost，助战自己的牵绊不计入总数。 |
| 必选从者牵绊优先 | 至少先在自有槽位选入一人，或将自动结果中的目标从者锁定。此目标优先提高必选从者的合计收益，再比较全队收益。 |
| 满破与持有等级 | 勾「满破」会按已收录的满破效果计算，借用礼装用助战数值。礼装等级用于显示和排序，单独改等级不会切换满破。 |
| 进阶条件 | 「全队额外加成（%）」填统一适用的额外百分比（0–1000）；「茶壶倍率」可选 ×1、×2、×3。「额外战斗礼装占位」和「额外预留礼装 Cost」可为未指定的战斗装备留空间。已经手动装入的战斗礼装会自动计入，别重复预留。 |

**看懂单人收益。** 例如基础牵绊为 1000，某自有从者可获得牵绊、适用的百分比加成为 25%，没有固定加成，也没用茶壶。在后排每场得 1250，在首发得 1500。计算时先将「基础 × 百分比」向下取整，加回基础及固定加成，再乘前排倍率（首发 1.2，替补 1）并向下取整，最后乘茶壶倍率。

### 绊15与自身上限

在「从者候选池」的每张卡下选择状态，完成后点「确认候选配置」。

| 页面选项 | 对这名从者和队伍的影响 |
| --- | --- |
| 正常获得 | 自身可获得牵绊。 |
| 未到15 · 已达上限 | 自身收益为 0。 |
| 绊15+ · 已满（全队+25%） | 自身收益为 0；实际出击时给全队加 25%。 |
| 绊15→16 · 可获得（全队+25%） | 日服选项。自身仍可获得牵绊，出击时也提供 25%。 |

多名自有绊15从者出击可叠加，放在替补也生效。仅留在候选池或借用绊15助战都不会触发这项被动。旧存档只有「已达上限」记录时，应按实际解锁情况重新选状态。

### 灵基、灵衣和头像

从者卡下方的「最优灵基 · 自动」允许求解器比较再临形态。要按自己实际使用的阶段计算，可直接在下拉框指定。默认自动搜索再临形态；要把灵衣也纳入自动搜索，在「进阶条件」勾「允许自动选择灵衣」。

例如，国服快照中鬼女红叶只有第1阶段满足满破「来自ＮＦＦ的爱」的兽科加成。装备后可在她的卡下展开「形态影响加成」，查看哪些阶段生效。请在游戏里选用对应战斗形象，关闭随机再临。网页的「切换头像」只改变卡片外观，计算仍按灵基下拉框和结果标注的形态进行。

## 戴冠战怎么编

1. 已有想保留的编队时，先保存为命名方案。打开「队伍编成」右上方的「戴冠战」，在「设定出发条件」选「出击职阶组」。**更换职阶组会清空当前编队、助战配置并恢复默认站位**，持有候选和已保存方案保留。
2. 页面按冠位钻研／认定战的职阶限制显示从者。可选七个常规职阶，或 EXTRA I（裁／仇／月／盾）、EXTRA II（丑／降／伪／兽）。选自有从者、助战和管理从者候选时都会限定出击范围。
3. 点带皇冠的「选择冠位从者」，选自己在游戏里已戴冠的从者；队内卡片也可点「设为冠位」。自有冠位会被纳入编队。是否具备游戏内戴冠资格由玩家确认。
4. 直接在冠位卡下装备。**普通槽**消耗正常 Cost；**报酬礼装**为 Cost 0，可指定、清槽或点「自动选优」；**牵绊礼装**为自身十绊礼装专用槽，可选「未装备」「开局 NP50%」「原有效果」，不额外提供一个通用牵绊加成位。
5. 借用冠位时勾「借用冠位助战」，核对其普通礼装、报酬礼装与各自满破状态。助战自己的两个槽须选择不同礼装。最后点「寻找最优队伍」。

## 三个常用场景

- **集中刷一名从者。** 先将目标放入自有槽，选「必选从者牵绊优先」，其余自有槽留给计算器。希望目标始终站首发时，再锁住其首发位置。看目标卡下的单人收益即可比较方案。
- **保留输出礼装。** 在打手的普通槽搜索「黑杯」并装备，锁定打手及该普通礼装，再让计算器用剩余 Cost 和槽位安排牵绊礼装。计算器比较牵绊收益，能否通关需自行判断。
- **保存不同职阶的队伍。** 在「保存 / 载入编队」中分别保存「弓阶钻研」「术阶钻研」等名称（最多 50 字符）。同名保存会询问是否覆盖。选中已有方案，点「载入方案」并确认，会一并恢复编队、持有候选和计算条件。

## 常见问题

**为什么搜不到昨天用过的卡？**  
先看服务器、搜索词、已启用的筛选，以及是否正处在戴冠战。搜索和页码会按选择入口记住，筛选与排序也会保留。清除搜索，再到「筛选」点「重置筛选」和「确认」。普通礼装槽提供完整礼装目录，「牵绊礼装候选」和冠位报酬槽只列已建模的牵绊礼装。

**候选礼装有数量上限吗？为什么计算很慢？**  
没有 12 种的选择限制。候选表示允许比较，实际装得下多少由人数、槽位与 Cost 决定；每种自有礼装按一张处理，自有普通槽与自有冠位报酬槽不能重复使用同一张。候选组合较多时可点「停止计算」，缩小到实际考虑的礼装后再算。

**提示「需要调整条件」，该改哪里？**  
看计算按钮下方的具体原因。先核对符合出击职阶的候选人数，再核对必选人数、必带礼装与剩余普通槽。最后检查固定卡与预留费用是否超出上限。只剩少数自有成员出击时，也要检查停用卡位中是否留有固定配置。

**为什么卡上的特性看似符合，却没有加成？**  
筛选特性会搜到「至少有一个形态符合」的从者，实际收益只看本次出击形态。一件礼装若要求「秩序且善」，两个特性必须同时满足。「兽科」、猛兽和 Beast 职阶也应分开判断。先查看该卡的形态说明，再核对满破和助战设置。

**刷新或换设备后，编队去哪了？**  
当前配置会在浏览器自动保存，命名方案按服务器另存。请用保存时的浏览器、网址和服务器查看；手机与电脑、GitHub Pages 与 ChatGPT Sites 之间不会自动互通。「重置全部」会重置当前服的工作编队和选择器偏好，已命名方案仍可从「保存 / 载入编队」找回。清除浏览器站点数据则会一并移除本机方案。

**显示载入失败、图片空白或无法保存怎么办？**  
数据载入失败时先刷新或切换服务器；本地运行应使用 README 中的 HTTP 服务。若只有卡图空白，检查与 Atlas 图片服务的网络连接。出现「无法读写本机存档」时，检查浏览器是否允许该站点存储，以及是否还有空间。
